# AI Programming 2 — C Coursework

C 언어로 좌표, 반복문, 애니메이션, 포인터를 연습한 수업 저장소입니다.

## What I Practiced

- ANSI escape code를 이용한 콘솔 좌표 이동
- 반복문과 좌표 계산으로 도형·경로 표현
- `Sleep`을 활용한 간단한 콘솔 애니메이션
- 함수와 포인터를 이용한 결과 반환
- Visual Studio 프로젝트 구성

## Selected Examples

| 소스 | 내용 |
|---|---|
| `1-2.c`, `1.c` | 좌표를 이동하며 사각형 경로 표현 |
| `2-1.c` | 심지 이동과 폭발 콘솔 애니메이션 |
| `2-2.c` | 포인터 인자를 사용한 합계 반환 |
| `AI_C2.c` | 반복문 기반 좌표 출력 |

## Environment

- Language: C
- IDE: Visual Studio
- OS: Windows
- 일부 예제는 `windows.h`와 Windows 콘솔 동작에 의존합니다.

## Run

`AI_C2.sln` 또는 하위 솔루션을 Visual Studio에서 열고 대상 프로젝트를 시작 프로젝트로 지정해 실행합니다.
